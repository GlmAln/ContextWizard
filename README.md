# ContextWizard – AI-Assisted Code Review for GitHub

ContextWizard is a GitHub App + Probot service that watches pull request review comments and replies with clearer, more actionable feedback generated by an LLM (via Perplexity’s API).

This README explains how to:

- Install and configure the ContextWizard GitHub App
- Run the Probot gateway locally
- Connect it to the Perplexity API
- Use it on your own repositories

---

## 1. Prerequisites

- Node.js 18+ and npm or yarn
- A GitHub account
- A Perplexity API key
- (Optional) `ngrok` or a similar tunneling tool for exposing your local Probot server to GitHub webhooks

---

## 2. Clone the project

```terminal
git clone https://github.com/your-org/contextwizard.git
```
