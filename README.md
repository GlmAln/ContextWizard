# ContextWizard

> A GitHub App built with [Probot](https://github.com/probot/probot) that ContextWizard is a plugin for GitHub for software teams that turn code review feedback that

## Setup

```sh
# Install dependencies
npm install

# Run the bot
npm start
```

## Docker

```sh
# 1. Build container
docker build -t ContextWizard .

# 2. Start container
docker run -e APP_ID=<app-id> -e PRIVATE_KEY=<pem-value> ContextWizard
```
